# LH PTB v3.7.0

## Template Studio
- Manual Template Calibration for each photo slot
- Drag each captured photo directly inside its slot
- Per-slot Zoom, X and Y controls
- 1 px-style fine nudging via compact directional controls
- Reset individual slot or all slots
- Preview and PNG export use the same calibrated slot coordinates
- Template artwork remains locked to its original aspect ratio
- Template Presets store PNG, slot order, position and zoom in browser local storage
- Up to 8 recent presets are retained

## Export
- Calibrated slot offsets and zoom are applied to the final PNG
- Template PNG is still rendered as the final foreground layer

## UI
- Added Template Studio control panel
- Added selected-slot tabs and calibration state indicator
