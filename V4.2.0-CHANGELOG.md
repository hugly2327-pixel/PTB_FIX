# LH PTB 4.2.0

## Photo saving and template workflow fix
- Automatic capture now saves original shots to the browser library but retains the captured images in the editor state.
- The editor remains open after capture so users can apply transparent PNG templates, layouts, captions, filters, and color adjustments.
- The composite image export, individual photo export, and combined save controls remain accessible.
- Video Recap generation is independent of the editor and no longer clears pending shots or closes the editor.
- If automatic library saving fails, the captured shots are still retained in the editor so the user can retry export.
- GitHub Pages-only package; no Android components.
