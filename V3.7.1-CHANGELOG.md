# LH PTB v3.7.1 — Template Export Alignment Fix

## Fixed
- Preview and exported Template photos now use the same cover geometry
- Each photo is clipped to its own slot during export
- Template Studio uses a per-slot overflow-hidden layer, preventing zoom/drag bleed
- Dragging uses the slot layer dimensions, matching export X/Y math
- Template artwork remains locked to its original aspect ratio
- Added a window pointerup safety handler so drag state cannot remain stuck

## Result
The position seen in Template Studio is now the position written into the exported PNG, within normal browser pixel rounding.
