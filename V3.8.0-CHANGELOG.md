# LH PTB 3.8.0 — Stability and Export Fixes

## Fixed
- Fixed the 2×3 layout export path so all six captured photos are included.
- Added an explicit validation message when a 2×3 export has fewer than six photos.
- Removed the duplicate GitHub Pages deployment workflow; `deploy-pages.yml` is the single deployment workflow.

## Improved
- Generalized the reusable photo composite export helper to support 4-photo (2×2) and 6-photo (2×3) exports.
- Generalized individual photo export helper to support 1–6 photos.
- Added a TypeScript type-check script.

## Compatibility
- Existing camera, editor, template, gallery, and 30-minute photo retention behavior are retained.
- No backend or remote image upload has been introduced.

## Validation
- Source-level checks are included in this delivery.
- A full production build still needs to be run in an environment with npm dependencies installed.
